# Documentation

This folder contains the reference material for Neon-Ai.

- `README_CYBERSEC.md` – detailed feature overview and security-focused model descriptions.
- `CYBERSEC_QUICK_START.md` – fastest way to deploy with recommended models.
- `architecture.md` – outline of the high-level system design and security pillars.

See the repository root `README.md` for headlines and a project map, or jump into `deploy/` to run the deployment tooling.
