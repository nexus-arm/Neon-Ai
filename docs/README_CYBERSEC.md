## 🚀 Quick Installation

```bash
# Download the enhanced script from GitHub Gist
wget https://github.com/nexus-arm/Neon-Ai/raw/main/deploy/deploy_cybersec_enhanced.py

# Make executable
chmod +x deploy_cybersec_enhanced.py

# Run with sudo (recommended)
sudo python3 deploy_cybersec_enhanced.py
```

> Note: When working from a cloned repo the script lives at `deploy/deploy_cybersec_enhanced.py`.

Or clone the entire repository:
```bash
# Clone the gist
git clone https://github.com/nexus-arm/Neon-Ai.git cyberpunk-ai-deployer
cd cyberpunk-ai-deployer

# Run the script
sudo python3 deploy/deploy_cybersec_enhanced.py
```

### Running Multiple Security Models

> If you cloned the repo, run the script via `sudo python3 deploy/deploy_cybersec_enhanced.py`.

```bash
# Install primary security model
sudo python3 deploy_cybersec_enhanced.py
# Select: [1] Lily-Cybersecurity-7B
```

### Model Management Commands

```bash
# List all installed security models
docker exec ollama ollama list

# Test specific security model
docker exec -it ollama ollama run seneca-cybersecurity:q4

# Remove unused model
docker exec ollama ollama rm model_name

# Pull model manually
docker exec -it ollama ollama pull whiterabbitneo:7b
```

### Security Hardening

```bash
# Firewall configuration
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp  # SSH
sudo ufw allow 3000/tcp  # Open WebUI
sudo ufw enable

# Fail2ban for SSH protection
sudo apt-get install fail2ban
sudo systemctl enable fail2ban
sudo systemctl start fail2ban

# Docker security
docker update --restart=unless-stopped ollama
docker update --restart=unless-stopped open-webui
```

## 🛠️ Troubleshooting

### Model Download Issues
```bash
# Check connectivity
docker exec ollama ping -c 4 huggingface.co

# Retry with specific timeout
docker exec -it ollama ollama pull model_name --timeout 3600

# Manual download alternative
wget https://huggingface.co/MODEL_URL
docker cp model.gguf ollama:/root/.ollama/models/
```

### Memory Issues
```bash
# Check available memory
free -h

# Limit model context size
docker exec ollama ollama run model_name --ctx-size 2048

# Use quantized versions
docker exec -it ollama ollama pull model_name:q4_0
```
